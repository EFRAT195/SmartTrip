# SmartTrip – סוכן AI לתכנון טיולים חכם

SmartTrip הוא יישום לתכנון טיולים בישראל באמצעות סוכן בינה מלאכותית (AI Agent), המתכנן מסלול אישי בהתאם להעדפות המשתמש, לזמן הפנוי, לתקציב ולתאריך הטיול.

המערכת משלבת מודל שפה, כלים לביצוע פעולות, בדיקות תקינות, מידע חיצוני על מזג האוויר וממשק משתמש אינטראקטיבי.

## הבעיה שהפרויקט פותר

תכנון טיול דורש בדרך כלל חיפוש אטרקציות, השוואת אפשרויות, בדיקת זמני ביקור ועלויות והתחשבות במזג האוויר.

SmartTrip מרכז את התהליך במערכת אחת ומאפשר למשתמש לקבל מסלול מותאם אישית בלי לבצע את כל הבדיקות בעצמו.

## כיצד המערכת פועלת?

המשתמש מזין חמישה פרטים:

- אזור הטיול
- סוג הטיול הרצוי
- מספר השעות העומדות לרשותו
- תקציב מקסימלי
- תאריך הטיול

לאחר שליחת הבקשה, הסוכן מבצע את הפעולות הבאות:

1. **חיפוש אטרקציות:** מפעיל כלי שמאתר אטרקציות מתאימות מתוך מאגר הנתונים של המערכת.
2. **בניית מסלול:** בוחר אטרקציות בהתאם להעדפות ולמגבלות שהוגדרו.
3. **בדיקת מגבלות:** מפעיל כלי שבודק אם המסלול עומד בזמן ובתקציב.
4. **תיקון החלטות:** אם המסלול אינו עומד במגבלות, הסוכן יכול לשנות את בחירת האטרקציות ולבצע בדיקה נוספת.
5. **בדיקת מזג אוויר:** מפעיל כלי שמקבל תחזית לתאריך ולאזור שנבחרו באמצעות שירות Open-Meteo.
6. **המלצות ציוד:** משתמש במודל AI כדי ליצור רשימת ציוד מותאמת למסלול ולמזג האוויר, כולל הסבר לכל המלצה.
7. **הצגת תוצאות:** מחזיר למשתמש מסלול, נתוני זמן ועלות, תחזית, המלצות ציוד ויומן פעולות.

## מדוע מדובר בסוכן AI ולא בצ'אט רגיל?

בצ'אט רגיל המשתמש שולח בקשה והמודל מחזיר תשובה.

ב־SmartTrip המודל אינו מסתפק ביצירת טקסט. הוא מפעיל כלים, מקבל מהם תוצאות, בודק אילוצים ומחליט כיצד להמשיך בתהליך.

הסוכן משתמש במנגנון Tool Calling, שמאפשר למודל לבחור ולהפעיל פונקציות במהלך העבודה.

**דוגמה לקבלת החלטה עצמאית:**

אם הסוכן בחר אטרקציות שמשך הביקור הכולל שלהן חורג ממספר השעות שהמשתמש הגדיר, כלי הבדיקה מחזיר שהמסלול אינו תקין.

בהתאם לתוצאה, הסוכן יכול לבחור מסלול אחר ולבדוק אותו מחדש.

כך מתקיים תהליך של בחירה, בדיקה ותיקון, ולא רק יצירת תשובה חד־פעמית.

## הכלים של הסוכן

| כלי | תפקיד |
|---|---|
| `search_attractions` | חיפוש אטרקציות לפי אזור וקטגוריה |
| `check_trip` | בדיקת עמידה במגבלות הזמן והתקציב |
| `get_weather` | קבלת תחזית מזג אוויר משירות חיצוני |

בנוסף, המערכת משתמשת במודל AI ליצירת המלצות ציוד אישיות.

## הוראות הרצה

### 1. התקנת ספריות Python

יש להתקין את התלויות הדרושות לשרת, בהתאם לייבואים בקוד. לדוגמה:

```bash
pip install fastapi uvicorn openai python-dotenv requests
```

### 2. הגדרת מפתח OpenAI

יש ליצור קובץ `.env` בתיקייה הראשית של הפרויקט ולהוסיף:

```env
OPENAI_API_KEY=your_api_key_here
```

אין להעלות את הקובץ הזה ל־GitHub.

### 3. הפעלת השרת

מתוך התיקייה הראשית:

```bash
uvicorn main:app --reload --port 64161
```

### 4. הפעלת ממשק המשתמש

ב־Terminal נוסף:

```bash
cd frontend
npm install
npm run dev
```

לאחר מכן יש לפתוח בדפדפן את הכתובת שמציג Vite, בדרך כלל:

`http://localhost:5173`
